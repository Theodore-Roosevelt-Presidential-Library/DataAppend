DataAppend ZIP Reference

Neighborhood-level income, education, age, housing and giving context for every U.S. ZIP code, built from free Census Bureau, IRS and USDA data and served as a static JSON API.

Using the API

Every file is static and public. No key, no rate limit beyond GitHub Pages.

PathReturns
zip/{ZIP}.jsonOne ZIP's record. A 404 means the ZIP isn't in any of the source files.
zips.csvAll ZIPs in one flat file, for batch joins.
meta.jsonBuild date, data vintages and source URLs.
fetch("zip/58645.json").then(r => r.json())

curl -s https://<this-site>/zip/58645.json

FieldMeaning

acs.top_codedMedians the Census caps: 250,001 means $250,000 or more; 2,000,001 means $2 million or more.

How to read it

These figures describe a neighborhood, not a person. A Tier A ZIP is a reason to look closer at a contact, never evidence of that contact's wealth. Use them for segmentation, regional planning and prioritizing research, and never in copy addressed to an individual.

  • Small places are noisy. Records flag small_population (under 500 people) and small_sample (under 250 tax returns). The IRS rounds counts and suppresses small cells, so a small ZIP can show 0% where the true figure is low but not zero.
  • Itemized figures undercount. Since 2018 most households take the standard deduction, so pct_returns_itemizing_charity and avg_itemized_real_estate_taxes mostly reflect higher-income itemizers. Compare ZIPs with it; don't read it as a giving rate.
  • ZIP and ZCTA differ slightly. Census data is by ZIP Code Tabulation Area, IRS data by postal ZIP. They match for most residential ZIPs.
  • The index averages national percentile ranks of median household income, share of households at $200K+, median home value, share with a bachelor's degree, and IRS average AGI (skipped for small samples), then ranks that average again. ZIPs under 200 people, or with fewer than three usable measures, get no index.
